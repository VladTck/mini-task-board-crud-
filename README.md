# Mini Task Board

Prosta aplikacja do zarządzania zadaniami z podstawowym CRUD.

### Funkcje

* dodawanie nowych zadań,
* wyświetlanie zadań,
* filtrowanie po statusie,
* edytowanie zadań,
* usuwanie zadań,
* obsługa nieistniejących zadań.

### Technologie

* Next.js
* TypeScript
* App Router
* Server Actions
* shadcn/ui

Dane zadań są przechowywane lokalnie w pliku `data/tasks.json`.

### Uruchomienie

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
